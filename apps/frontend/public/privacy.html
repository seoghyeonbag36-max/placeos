로그인하지 않고 지도와 분석 화면을 둘러보는 경우, 서비스는 계정 정보를 받지 않습니다. 다만 모든 웹 서비스처럼 서버 호스팅 제공사가 접속 기록(IP 주소, 요청 시각·경로 등)을 운영·보안 목적으로 일정 기간 보관할 수 있습니다.

2. 보관 기간과 파기

  • 계정을 유지하는 동안 보관합니다.
  • 탈퇴하면 바로 지웁니다. 계정 화면 맨 아래 「회원 탈퇴」에서 확인을 거치면 처리됩니다. 네이버·카카오 로그인 제공자와 고유 사용자 ID도 함께 삭제합니다.
    • 혼자 쓰던 조직이면 사용자·조직·API 키·사업 정보·피드백·이용 기록을 모두 지웁니다.
    • 다른 멤버가 남아 있는 조직이면 본인의 계정·멤버십·사업 정보·피드백을 지우고, 조직은 남은 멤버를 위해 유지합니다. 본인 이름이 붙었던 이용 기록은 사용자 식별자를 비워 누구의 것인지 알 수 없는 집계로만 남깁니다.
  • 데이터베이스 제공사가 장애 복구용으로 두는 시점 복구 기록에는, 그 서비스가 정한 보존 기간 동안 삭제 전 내용이 남아 있을 수 있고 기간이 지나면 함께 사라집니다.
  • 현재 유료 결제를 받지 않아 법령에 따라 따로 보존해야 하는 정보는 없습니다.

3. 제3자 제공

법령에 근거한 요청이 있는 경우를 제외하고, 개인정보를 제3자에게 제공하지 않습니다.

4. 처리 위탁과 국외 이전

5. 이용자의 브라우저가 직접 접속하는 외부 서비스

네이버 로그인·카카오 로그인 버튼을 누르면 브라우저가 해당 제공자의 로그인·동의 화면으로 이동합니다. PlaceOS 서버는 인증 코드를 교환한 뒤 고유 사용자 ID와 제공된 이메일을 확인합니다. 제공자의 비밀번호는 PlaceOS에 전달되지 않으며, 로그인용 접근 토큰·갱신 토큰은 저장하지 않습니다. 현재 탭에 로그인 요청 확인값을 일시 보관하며 인증 처리 때 제거합니다.

아래는 서비스가 정보를 보내는 것이 아니라, 이용자의 브라우저가 해당 서비스에 직접 접속하는 경우입니다. 각 서비스의 개인정보 처리방침이 적용됩니다.

  • 구글 로그인 — 「Google 계정으로 계속하기」를 쓰면 브라우저가 구글과 직접 통신합니다. 서비스는 구글이 서명해 준 확인서에서 이메일 주소만 확인해 씁니다.
  • 네이버 지도 — 로그인 후 지도 화면에서 브라우저가 네이버 지도 서버에 직접 접속하며, 이때 IP 주소·브라우저 정보가 네이버에 전달됩니다. 서비스는 이 정보를 받거나 저장하지 않습니다.
  • 카카오맵 링크 — 「카카오맵에서 열기」를 눌렀을 때만 카카오맵으로 이동합니다.

6. 쿠키와 접속 정보

서비스는 광고·추적 목적의 쿠키나 분석 도구를 쓰지 않으며, 서비스가 직접 설정하는 쿠키도 없습니다. 로그인 상태는 브라우저의 세션 저장소에만 두므로 탭이나 브라우저를 닫으면 사라집니다. 다만 5.에 적은 구글·네이버 같은 외부 서비스는 자체 쿠키를 둘 수 있습니다.

7. 이용자의 권리

  • 계정 화면에서 본인의 이메일과 API 키 목록을, 「내 사업」 카드에서 입력해 둔 사업 정보를 직접 확인하고 고칠 수 있습니다.
  • 탈퇴는 계정 화면에서 직접 하며, 그 즉시 2.에 따라 지워집니다.
  • 화면에서 처리되지 않는 열람·정정·삭제·처리정지 요청은 아래 보호책임자 이메일로 보내 주세요. 지체 없이 처리하고 결과를 알려 드립니다.

8. 안전성 확보 조치

  • 비밀번호는 단방향으로 암호화(bcrypt)해 저장하고, API 키는 해시만 저장합니다.
  • 모든 통신은 HTTPS 로 암호화되며, 사업 정보는 본인 계정에서만 조회됩니다.
  • 로그인 토큰은 탭을 닫으면 사라지는 세션 저장소에 두고, 로그아웃한 토큰은 재사용을 막습니다.
  • 이용 기록에는 이메일을 적지 않아, 탈퇴 때 지울 곳을 줄였습니다.

9. 아동

PlaceOS 는 창업을 준비하거나 사업을 하는 분들을 위한 서비스이며, 만 14세 미만 아동을 대상으로 하지 않습니다.
