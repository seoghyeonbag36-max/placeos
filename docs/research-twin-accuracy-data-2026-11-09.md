사용자 요청: 「3D 디지털 트윈의 정확성을 높이기 위해 필요한 데이터들 조사」. 트윈의 각 요소가 지금 무엇에 기대고 있는지(실측 · 계산 · 추정 · 개략)와,

## 6. 상가정보 호수 — Gold 재빌드 절차 (수집 PC)

이 저장소 체크아웃에는 bronze(`stores_raw.json`)가 없다(gitignore · 수집 PC 에만 있다). 그래서 전 거점 `stores_lite` 재빌드는 수집 PC 에서 한다.

```bash
python -m data.pipelines.build_stores_lite          # ACTIVE_HUBS 전부 — fields 끝에 "ho" · 문서에 n_with_ho
python -m pytest data/tests/test_renewal_gold.py -k "stores_lite or store_ho or lite_doc"
git add data/gold/*/stores_lite.json.gz data/gold/platform_store_brands.json data/gold/platform_industry_colocation.json
```

- 재빌드 전 판(8칸)도 서버 · 시험이 그대로 받는다(`LITE_FIELDS_V1`). 앞 8칸 자리는 바뀌지 않는다.
- 재빌드 전에도 트윈은 서버 키로 그 건물을 실시간 조회해 호실 대조를 한다 — Gold 는 실시간 조회가 안 될 때의 대안이다.
- 재빌드 뒤 거점별 `n_with_ho / n` 을 보고, 0% 에 가까우면 상가정보가 호를 안 주는 것이다(08-30 판정과 같음) — 그때는 호실 대조를 다른 원천(임대인 · 관리사무소 자료 §4-16)으로 채운다.
