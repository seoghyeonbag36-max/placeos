## 사용자가 직접 확보해야 하는 운영 원본

현재 연결된 POS·예약·회원관리 계정이나 제공받은 사업자 파일이 없어 아래 원본은
자동 수집하지 못했다. 공개 집계로 이를 대신 채우지 않았다.

| 업종·데이터 | 누구에게 요청하나 | 어떻게 받을지 | 요청 항목 |
|---|---|---|---|
| 술집 실제 매출·시간대 거래 | 참여 점포주·POS 관리자 | 사용 중인 POS에서 기간별 매출·상품분석 Excel 내보내기 | 점포 ID, 기준일·시간대, 거래 수, 매출·취소액, 메뉴 유형, 영업시간 |
| 미용·네일 예약·재방문 | 점포주·예약/고객관리 프로그램 관리자 | 월별 예약·방문·취소·재방문 집계 파일. 내보내기가 없으면 해당 프로그램 지원팀에 집계 추출 요청 | 시술 유형, 월, 예약/완료/취소 수, 재방문 수, 집계 정의 |
| 옷·잡화 판매·반품 | 점포주·POS/재고관리 관리자 | 상품군별 월 판매·환불 Excel 추출 | 상품군, 판매 건수·매출·반품 건수/금액, 오프라인/온라인 구분 |
| 학원 수강생·유지율 | 학원장·학원 관리프로그램 담당자 | 월말 재원생·신규등록·퇴원·정원·수강료 집계 | 과정·대상 학령, 월, 정원, 재원생·입퇴원 수, 청구/수납/환불 구분 |

초기 요청 기간은 **최근 12개월**, 가능하면 24개월을 제안한다. 이는 확보 목표이며
모델의 검증된 최소 표본 기준이 아니다. 보유 기간이 짧으면 실제 기간을 적고 빈 기간을 보간하지 않는다.
점포 주소·층·호실·운영 기간을 함께 받아 공개 위치 데이터와 연결한다.
고객 이름·전화번호는 요청하지 않고 점포별 집계를 받는다.

### POS 내보내기 방법이 확인된 예: 토스플레이스

[공식 매출 리포트 가이드](https://guide.tossplace.com/operate/sales-report):

1. 점포주가 포스 메뉴 `≡ → 매출 리포트 → 엑셀 내보내기`를 연다.
2. 기간과 일별/주별/월별 집계 기준을 고르고 파일을 생성한다.
3. 한 번에 최대 6개월이므로 12개월이면 두 구간으로 나눈다.
4. 파일 비밀번호를 설정하고 다운로드 리스트에서 받는다. 생성 후 3일 이내 내려받는다.
5. 실제 파일의 집계 범위·취소·할인 반영 여부를 함께 전달한다.

다른 POS·예약·학원·회원관리 제품은 메뉴가 다르므로 해당 제품 관리자에게 같은 필드의
집계 내보내기를 요청한다. 개별 시스템에서 모든 항목을 제공한다고 가정하지 않는다.

`data@kcd.co.kr`로 공급 가능 범위와 조건을 문의할 수 있다. 이번 작업에서는 문의를 발송하지 않았다.

월/시간대 매출·거래·반품·재방문 집계, 공간 입도, 익명 점포 연결키, 제공 가능 기간,
기준일·결손·표본 범위, 가격, SaaS 분석·학습·결과 제공 허용 범위.
실제 제공 필드·가격·계약 가능 여부는 회신을 받아야 확정된다.
