## 범위와 출처

앞서 확인한 R-ONE 앵커 13개를 각각 한 후보로 조사한다. 서빙 거점 확정이 아니다.
공공시설·역·대학의 V-World 검색 좌표를 조사 중심으로 삼고, 겹치는 반경은 절반으로
줄였다. 이 중심과 반경을 R-ONE 상권 경계라고 표시하지 않는다. 카카오 응답은 저장하지 않았다.

- 설정·수집: `data/collectors/gwangju_candidates.py`, `gwangju_licensing.py`.
- 출처: 소상공인 상가정보, V-World 검색·건물 WFS, R-ONE, 네이버 블로그 검색,
  행정안전부 일반음식점 조회서비스. 합성값은 사용하지 않았다.
- 통과 조건: `data/tests/test_gwangju_collection.py`, `data/tests/test_gwangju_capacity.py`.
- 금지: 기존 Gold 덮어쓰기, 시드 보충, 출처·앵커 판정 규칙 변경, PPPP 화면 변경,
  쿼터 소진 상태의 건축HUB 반복 호출, 커밋·푸시·배포.

## 키와 인허가

R-ONE·공공데이터포털·V-World·네이버 키가 설정되어 있고, 이번 실호출이 정상 응답했다.
행안부 일반음식점 API도 기존 `DATA_GO_KR_SERVICE_KEY`로 HTTP 200·결과코드 0을
확인했다. 이번 수집에는 **추가 키 발급이나 활용신청이 필요하지 않았다**.
일반음식점 한 업종의 권한 확인을 다른 인허가 업종 전체의 권한으로 확대하지 않는다.

공식 명세: https://www.data.go.kr/data/15154916/openapi.do
실호출: `https://apis.data.go.kr/1741000/general_restaurants/info`.
도로명 주소 프로브에서 관측한 개방자치단체코드로 5개 구 전량을 페이지 수집한다.
완주한 구만 `_complete.json`을 남기고, 실패하면 다음 실행에서 페이지 캐시부터 재개한다.
진행·결과 보고서는 `reports/gwangju_licensing_collection_2026-10-28.json`이다.

5개 구 모두 완주했다. 동구 8,777·서구 12,891·남구 7,562·북구 17,491·광산구
14,040건으로 총 **60,761건**이다. 영업·폐업 등 상태를 포함한 일반음식점 인허가
전체 건수이며 현재 영업 점포 수가 아니다. 서구는 일시 오류 뒤 저장 페이지에서
재개했다. 구별 API totalCount와 페이지 합계·관리번호 고유 건수를 대조했다.
후보별 핵심 원본 39개의 SHA-256도 검증했다.

종합 결과는 `reports/gwangju_collection_summary_2026-10-28.json`,
원본 해시는 `reports/gwangju_collection_artifacts_2026-10-28.json`에 남겼다.
지역·시설 검증, 부분 수집 실패, 인허가 권한 오류, 앵커 산정 테스트 6개가 통과했다.

## 멈춘 단계

원본 제공자의 주소 표기는 `전남광주통합특별시`, 시군구·PNU는 `122xx/123xx`인 반면
점포의 건물관리번호는 과거 `29xxx`를 포함한다. 이는 **관측한 원본 필드 차이**이며,
이 문서에서 법적 행정구역 개편 여부나 신구 코드의 1:1 대응을 확정하지 않는다.
이를 임의 치환하면 건물·인허가 조인이 틀릴 수 있어 Bronze만 보존했다.
대장 쿼터도 이미 소진된 상태이므로 추가 대장 호출·Silver/Gold 승격·서빙은 수행하지 않았다.
소규모 임대료가 없는 어룡동·우산동·일곡동은 기존과 같이 빈 값으로 둔다.
