# 3D 디지털 트윈 담당에게 — 고양·파주에서 Page 가 못 덮는 자리 (2026-11-23)

> 읽는 사람: 3D 디지털 트윈(계획상가·집합건물)을 맡을 팀원. 사용자 결정(11-23 ②): **임대 앵커와 계획상가 천장은 우선 별도로 표시만 해 두고, 3D 트윈 담당이 다룬다.**
> 이 문서는 「어디가 비어 있고, 왜 Page 가 못 덮고, 무엇을 이미 갖고 있나」만 적는다. 결정·근거 원문은 아래 링크.

## 1. 한 장 요약

| | 고양 | 파주 |
|---|---:|---:|
| 도시 점포 | 50,083 | 24,550 |
| **보류 거점(계획상가·단일시설) 반경 안 점포** | **13,410 (26.8%p)** | 1,526 (6.2%p) |
| 보류 거점 | 계획상가 6(화정·라페스타·웨스턴돔·탄현·마두·주엽) + 단일시설 3(킨텍스·스타필드·삼송) | 계획상가 1(운정 목동) + 단일시설 1(파주 프리미엄아울렛) |
| 계획상가 밀집 **신규 후보**(건물당 점포 >10) — **보류로 등록·수집 중**(`GOYANG_PAJU_CEILING_HUBS`, 11-23) | 향동(화전동) 29.4 · 마두동 동측 10.2 · 일산3동 10.2 | 금촌2동 16.7 · 운정1동 14.5 · 운정6동 14.2 |

- **가장 큰 한 덩어리**: 고양 일산동구 **장항2동 4,854곳 · 건물당 30.3곳**. 무게중심이 라페스타 370m · 웨스턴돔 299m — 일산 계획상가 띠 한가운데다. 그중 **4,453곳(92%)은 이미 보류 거점(라페스타·웨스턴돔 등) 반경 안에서 수집돼 있고**, 어느 등록 거점에도 안 닿는 점포는 401곳뿐이다. 상위 업종은 과학·기술 · 음식 · 소매 · 수리·개인. 건물 용도는 **대장 기준으로 확정하지 않았다**(지식산업센터·상가 복합으로 읽히나 추정이다).
- 왜 Page 가 못 덮나: 우리 공실 분모는 **건축물대장 일반건축물**이다. 건물당 점포 >10 이면 점포 대부분이 집합건물 호실이라 분모가 재고 일부만 덮는다(화정은 건물당 7.7 이었지만 집합 비중이 93% 였다).

## 2. 두 천장은 서빙 여부와 따로 적혀 있다

`reports/citywide_census_{goyang,paju}.json` 의 `hubs[]` — 거점마다
- `ceiling_planned_store` : `계획상가` · `단일시설` · 빈 칸(= 해당 없음)
- `ceiling_rone_anchor` : `정확` · `공유` · `없음` , `rone_series` : 빌려 쓰는 R-ONE 표본
- `state` : `서빙` · `보류(계획상가|단일시설)` · `등록만`

임대 앵커 천장: 고양시청·탄현역·파주시청 **셋뿐**이라 거점을 늘려도 정확 매핑은 늘지 않는다. 서빙 9곳 중 정확은 금촌 하나다. 3D 트윈 거점이 임대 시세를 쓰려면 같은 한계(공유 표본)를 받는다.
