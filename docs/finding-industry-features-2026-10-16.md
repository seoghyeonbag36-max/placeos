## 2. 무엇을 했나

### 2-1. 후보 탐색 (파일로 확인한 것만)

세부 업종 실험 그래프(61,165노드·27클래스)의 기존 132피처는 `train_gnn._features` 가 만든다. 거점 원핫·상대좌표·
건물 규모·밀집도, **TRDAR 상권 수요 37열(연령 구성비 6·유동 시간대 6·매출 시간대 6·주말 비중 포함)**, 건물
대장 10열이다. 따라서 문서가 「후보」로 적은 야간 수요·고객 연령은 **상권(TRDAR) 단위로는 이미 들어 있다.**
이번에 검토한 것은 그 밖의 입지 입력이다.

### 2-2. 피처 정의 (`ml/training/industry_detail_features.py`)

- **floor 5열**: 층 해석 가능 여부 · 지하(`지`·`B*`·`반지층`) · 1층 · 2층 · 3층 이상(로그). 공란과 호실 번호로
  보이는 값(`403`, `B145` 등 31 이상)은 층으로 추측하지 않고 「모름」으로 둔다. 층은 공실 자리에서도 관측되는
  자리 속성이다(`vacant_floor_units`).
- **transit 4열**: 노드 300m 안 정류소 수(로그) · 합산 일평균 승하차(로그) · 최근접 정류소 거리(로그) · 최근접
  정류소 승하차(로그). z-score.
- **hourly 10열**: 행정동 평일/주말 피크 시각·저녁·야간·아침 비중·총량·피크성. 귀속 안 된 노드는 같은 거점 평균,
  그것도 없으면 전체 평균으로 채운다(기존 코드 그대로).

`train_gnn.train()` 은 고치지 않았다. 실험 스크립트가 실행 시점에 `_features`(블록 덧붙임)와 `_split`(분할 시드
고정)만 바꿔 끼우고, 끝나면 되돌린다. MLflow 는 별도 실험명 `industry_detail_features` 에 쓴다.

### 2-3. 비교 설계

- **같은 분할**: 분할 시드 42 고정(층화 60/20/20). 모든 팔·시드가 같은 test 12,243노드를 쓰며 스크립트가 노드 순서
  일치를 검사한다. **거점 사전분포 기준선도 같다**(train 라벨만으로 센 거점별 상위 3업종).
- **같은 설정**: 80 에포크·patience 15·hidden 64 (10-16 보고서와 동일). 보강 전(control) 시드 42 는 기존
  `industry_detail_experiment_2026-10-16.json` 의 test Top-3 53.01%·기준선 45.41% 를 **소수점까지 재현**했다
  (`reproduces_prior_report.match = true`, 입력 해시도 일치).
- **학습 시드 3개**(42·43·44, 분할은 고정): 업종 하나가 시드에 따라 몇 %p 흔들리는지 보기 위해서다. 예로 요리 주점은
  보강 전에도 시드별로 80.3 / 79.0 / 78.2% 였다. 아래 업종별 수치는 **시드 3개의 평균**이라 10-16 보고서의
  단일 실행 수치(요리 주점 80.30%)와 조금 다르다.
- **모델 선택과 보고 분리**: 조기 종료·체크포인트 선택은 학습기 기본값(val Top-1)이고 test 는 선택에 쓰지 않았다.
  묶음을 「채택」하는 판단이 필요하면 근거는 val 이어야 하며, 표 C 의 val Top-1 은 test 순서와 같다
  (floor·all ≈ 33~34% ≫ control·transit·hourly ≈ 31%).
- **구간**: 시드 평균 적중(0/1)을 노드별로 구하고 **거점 군집 부트스트랩**(거점 단위 재표본 2,000회)으로 95% 구간을
  낸다. 구간은 test 표본 변동만 담고 학습 시드 변동은 「시드별」 열로 따로 본다. 구간이 0 을 품으면 「구분불가」다.
  test 표본 0 인 업종은 `null`(산출 불가)로 둔다 — 공연장·전시장·갤러리.
- 임계값(70% 등)은 쓰지 않았다. 판정은 같은 표본의 기준선과의 차이와 구간이다.

## 5. 한계 (읽을 때 지킬 것)

1. **태스크가 추천이 아니다.** 현존 점포의 소분류를 이웃·입지만으로 맞히는 분류다. 층이 도움 된다는 것은 「이 층에는
   이런 업종이 이미 있다」는 사실의 반영일 수 있고, 그 업종이 거기서 잘된다는 근거가 아니다.
2. **분할이 노드 무작위 층화**라 같은 거점·같은 건물의 점포가 train·test 에 섞인다. 미관측 거점·미래 시점 일반화는
   검증하지 않았다(`industry_detail_experiment.py` 의 한계와 같다).
3. **서빙에서 층을 넘기는 경로는 이 실험 범위 밖이다.** 서빙 JSON 은 노드(현존 점포) 단위이고, 공실 유닛의 층을 모델
   입력으로 넣는 경로는 연결돼 있지 않다.
4. **시드 3개**는 학습 변동의 추정이 거칠다. 구간은 test 표본 변동만 담는다.
5. **다중비교 미보정**: 업종 27개 × 묶음 4개를 봤다.
6. hourly 의 행정동 귀속률은 60.3%(59개 거점·134개 행정동)이고 나머지는 거점 평균·전체 평균으로 채웠다. 집계구
   수준의 시간대 유동은 노드 배정표가 비어 있어 **시도조차 못 했다.**
7. 층 해석 불가 28.5%(공란·호실 번호)는 「모름」 열로 들어간다.
