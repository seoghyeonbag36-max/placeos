# 공고 대기·다음 시즌 출품 준비 키트 (예상 오픈 순)

지금 접수 중인 자리가 아니라 **아직 열리지 않았거나 이후에 열릴 자리**를 오픈 예상 시점 순으로 놓고, 공고가 뜨기 전에
해 둘 일과 쓸 재료를 모았다. 날짜는 모두 작년·올해 접수 실적에서 추정한 것이고 공고 원문으로 확인하지 못했다.
공고가 뜨면 아래 '먼저 확인'부터 한다 — 확인 전에는 원고를 쓰지 않는다.

## ② 10월 중 — 한국부동산원 논문 공모 (제3회)

**준비 완료.** [논문제안서 원고](../11-reb-paper/proposal.md)(Posting 트랙 · Word 본: `11-reb-paper/proposal-2026-10-06.docx`).

## 공통 규칙 (이 키트의 모든 자리)

1. 공고 원문·서식을 열기 전에는 제출용 원고를 쓰지 않는다 — 이 키트의 절 구성은 모두 가설이다.
2. 수치는 [claims.json](../claims.json) 밖에서 가져오지 않는다. 마스터 원고의 숫자는 현재 대장 값이다.
3. M&A·구독 가격·고객사 실적·지자체 협의 이력은 쓰지 않는다(없다). 공공 트랙은 시민·공공의 언어로 쓴다.
4. 한계 절은 줄이지 않는다. 현실 공실 정확도는 아직 평가하지 못했다.
5. 동시에 두 개 이상 쓰지 않는다.
