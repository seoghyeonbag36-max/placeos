## 1. 사회현안 정의

골목상권의 빈 점포는 쇠퇴의 증상이면서 원인입니다. 정보 없이 계약하고, 검증 없이 개업하고, 조기에
폐업하면 다시 공실이 되고, 빈 점포가 늘수록 발길이 줄어 다음 창업이 더 어려워집니다.

이 고리가 도는 원인은 **정보의 비대칭**입니다.

| 원인 | 현재 상태 | 이 서비스가 닫는 방식 |
|---|---|---|
| 상권 단위까지만 답하는 공공 통계 | 공실률·임대료는 상권·분기 단위. "어느 건물 몇 층이 왜 비었는가"에는 답이 없다 | 건물·층 단위로 내려 읽는다 |
| 흩어진 자료 | 건축물대장·상가정보·인허가·임대동향이 기관별로 따로 공개 | 건물 고유번호(PNU)로 결합한다 |
| 개업뿐인 확인 수단 | 아이템이 통하는지는 계약·인테리어·개업 뒤에야 안다 | 팝업·가오픈·MVP 로 계약 전에 작게 검증한다 |
| 출발선의 차이 | 상권분석 조직이 있는 본사와 달리 개인은 발품과 설명에 의존 | 같은 근거를 개인에게도 연다 |

## 2. 서비스 설계

### 2-1. 이용자 흐름

| 단계 | 질문 | 화면 | 산출 |
|---|---|---|---|
| ① 상권 읽기 | 이 상권은 어떤 곳인가 | 업종 추천 · 분기 추세 | 상권의 성격과 업종 궁합 |
| ② 빈 자리 찾기 | 어느 건물 몇 층이 비었나 | 공실 히트맵 · 층 스택 · 네이버 거리뷰 | 후보 자리 목록과 외관 |
| ③ 비용 판단 | 어느 비용 규모로 들어갈 수 있나 | 입점 비용 비교 (고급화·가성비·기능중심) | 월 순익·회수기간 비교 |
| ④ 작게 검증 | 이 아이템이 여기서 통하나 | 검증 program 브리프 | 모객·자리·상권 연계 + 판정표 |

### 2-2. 검증 program 판정표 — 이 서비스의 중심

무엇을 세면 "통했다"고 볼지를 **시작 전에** 정합니다. 판정표는 지표 · 측정 방법 · 목표선 · 기각 조건
네 칸이고, 기각 조건이 없는 검증은 결과를 본 뒤 말을 맞추게 되어 판정이 아니라 지출이 됩니다. 검증
program 초안은 규칙 기반 검사가 근거 없는 주장과 기각 조건 누락을 걸러낸 뒤에 내보냅니다.

### 2-3. 빈 자리가 검증 무대가 되는 구조

②에서 찾은 빈 자리가 ④의 팝업 무대가 됩니다. **공실이 문제이면서 동시에 검증 자원이 되는 구조**이고,
이것이 단순 상권분석 서비스와 이 제안의 차이입니다.

## 3. 디지털 기술과 공공데이터

### 3-1. 데이터 — 전량 공개 공공데이터

국토교통부 브이월드(GIS건물통합정보), 건축HUB(건축물대장 전유부·층별개요), 소상공인시장진흥공단
상가(상권)정보, 행정안전부 지방행정 인허가, 한국부동산원 상업용부동산 임대동향, 서울
열린데이터광장(상권분석·생활인구)을 공식 API 로 받습니다. 수집기가 저장소에 있고 실행 명령이
문서화되어 있어 제3자가 같은 경로로 다시 받을 수 있습니다. 출처·라이선스 표는 별첨(data-sources)에 있습니다.

### 3-2. 구조

공공 API 수집기 → Bronze(원본 보존) → Silver(정제) → Gold(서빙용 산출물) → FastAPI → React·네이버 지도.
거점 수와 진행률은 문서가 아니라 산출물을 직접 세는 스크립트가 단일 출처입니다.

### 3-3. AI — 무정보 베이스라인 대비로만

| 모델 | 모델 성능 | 같은 표본의 무정보 베이스라인 | 차이 (95% 구간) | 판정 |
|---|---|---|---|---|
| 업종 추천(GNN) · Top-3 | 92.0% | 거점 사전분포 기준선 88.7% | +3.36%p [+2.78, +3.95] | 실력 (시험 17,650자리) |
| 공실 예측(LSTM) · 오차 | MAE 0.822 | 두 무정보 규칙 중 강한 쪽 — 거점 평균 MAE 0.998 (지속성 1.190) | 기술점수 +17.6% [+11.6%, +24.5%] | 참고 판정 · 확정 전 |
| 공실 예측(LSTM) · 방향 | 80.0% (192/240) | 두 무정보 규칙 중 강한 쪽 — '평균 쪽' 규칙 68.8% ('항상 하락' 55.0%) | +11.3%p [+5.4, +17.1] | 참고 판정 · 확정 전 |

업종 추천은 서울 81거점의 건축물대장 기반 산출물 위에서 학습·평가했습니다. 공실 예측은 확정 전이며,
확정은 모델이 한 번도 보지 않은 2026년 3분기 데이터로만 합니다. 그 전까지 화면은 직전 분기 기준 추세를
기본값으로 보여 주고 LSTM 예측은 '실험 모델'로 접어 둡니다.

### 3-4. 개인정보

분석 단위는 건물·층·상권입니다. 개인의 신용·거래 정보는 수집도 저장도 하지 않으며 민간 데이터도
크롤링이 아니라 공식 API 로만 받습니다.

## 5. 한계

이 절은 빼지 않습니다.

1. **건축물대장 기반 산출 공실률의 현실 정확도는 아직 평가하지 못했습니다.** 원천 자료들의 관측 시점이
   서로 달라 전 거점을 같은 시점으로 맞출 수 없고, 사람이 정답을 붙일 독립 검토 표본 211개는 아직 전부
   미확정(unresolved) 상태입니다. 그래서 '실측'이라 부르지 않습니다.
2. **층 배정에는 범위가 있습니다.** 정보가 부족한 건물은 공실을 한 층에 배정하지 못해 범위로 냅니다.
   층 배정 범위 폭의 중앙값은 16.2%p 이며 통계적 신뢰구간이 아닙니다.
3. **공실 예측은 확정 전입니다.**
4. **검증 program 의 효과(실제 창업 성패 개선)는 측정한 적이 없습니다.** 판정표가 있다는 것과 그것이 창업
   성과를 높였다는 것은 다른 주장이며, 후자는 아직 근거가 없습니다.
5. **지자체·기관과 협의하거나 시범 적용한 적이 없습니다.** 아래 6절의 협력은 계획입니다.

## 6. 공모 기간 고도화 계획

| 순서 | 과제 | 닫으려는 한계 | 완료 판단 |
|---|---|---|---|
| 1 | 시민 참여형 공실 확인 — 현장 확인 결과를 독립 검토 표본의 정답으로 쌓는다. 기록에 개인 식별 정보를 남기지 않는다 | 한계 1 | 표본에 사람 정답이 붙어 오류율과 오류 방향(과대·과소)을 잰다 |
| 2 | 검증 결과의 공공 환류 — 판정표 결과를 익명·집계로 쌓아 같은 상권의 다음 창업자가 참고하게 한다 | 한계 4 | 집계 결과가 화면에 나온다 |
| 3 | 빈 점포 활용 공공 사업과의 연결 — 대상지 선정 근거를 제공하는 모델을 설계한다 | 한계 5 | 협력 대상과 제공 범위를 문서로 확정 |
| 4 | 서울 밖 원도심 확장 — 거점 체인 절차로 데이터 가용성을 먼저 확인한 뒤 적용한다 | — | 대상지의 데이터 가용성 판정서 |

## 7. 기대효과

- **예비창업자** — 목돈을 쓰기 전에 작게 검증해 실패를 계약 전 단계에서 줄이는 것을 기대합니다.
- **골목상권** — 빈 점포가 검증 무대로 쓰여 공실로 멈춰 있는 기간이 줄어드는 것을 기대합니다.
- **행정** — 건물·층 단위 공실 현황을 사후가 아니라 사전에 파악합니다.
- **공공데이터** — 이미 공개된 자료의 결합만으로 새 판단 근거를 만들어 시민에게 돌려줍니다.

위 효과는 모두 **기대**이고 측정된 결과가 아닙니다(한계 4).
