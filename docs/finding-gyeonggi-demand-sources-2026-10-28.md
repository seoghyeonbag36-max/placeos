# 경기 유동인구·수요를 대신할 무료 소스 — 무엇을 신청하면 되나 (2026-10-28)

> **사용자 질문(2026-10-27)**: 「경기 유동 인구·수요 데이터를 대신할 소스를 얻을 수 있기 위해서 어떤 API 를 발급받아야 하는지 알려줘.」
>
> 배경: 서울은 서울시 상권분석(TRDAR 추정매출·유동)과 생활인구로 유동 등급(Posting)·상권 수요신호(Program)를 만든다. 고양·파주에는
> 그 소스가 없어 두 축이 비어 있다(결정 문서 `decision-goyang-paju-corridor-2026-10-26.md` §5). 유료 SaaS 화면에 들어가는 숫자라
> **상업적 이용이 허용**돼야 하고, 지금은 무료 소스만 쓴다.

## 0. 결론 — 새로 「발급」받을 키는 없다, 데이터셋별 「활용신청」이 필요하다

이미 가진 키(이름만): 공공데이터포털 `DATA_GO_KR_SERVICE_KEY` · 경기데이터드림 `GG_OPENAPI_KEY` · 통계청 SGIS `SGIS_CONSUMER_KEY/SECRET` ·
`KOSIS_API_KEY` · 서울 열린데이터 `SEOUL_OPENAPI_KEY` · 한국부동산원 `REB_RONE_API_KEY` · 카카오·네이버·V-World.
공공데이터포털은 키 하나로 쓰되 **데이터셋마다 활용신청**을 따로 해야 한다(안 하면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`).

| 우선 | 소스 | 무엇을 주나 | 단위 | 이용허락 | 할 일 |
|---|---|---|---|---|---|
| 1 | 행정안전부_행정동별(통반단위) 성/연령별 주민등록 인구수 (data.go.kr 15108072) | 배후 거주 인구 · 성·연령(만 0~100세+) | 행정동(통·반) · 매월 | 제한 없음 | **활용신청**(개발·운영 자동승인 · 개발 하루 10,000건) |
| 2 | 한국철도공사_광역철도 수송인원 및 승하차인원 (data.go.kr 15154382) | **역별 · 시간대별** 승하차(개표 태그 실적) | 역 · 시간대 | 제한 없음 | **파일(XLSX) 내려받기** — API 아님 · 신청 불필요 |
| 3 | 경기도_정류소 별 승하차 인원 집계 (data.go.kr 15144886) | 버스 정류소별 일 승하차·환승 | 정류소 · 일 | 제한 없음 | 파일 내려받기(전체) · API 는 상세 사양이 비어 있어 신청 전 확인 |
| 4 | 통계청 SGIS 오픈API | 집계구 인구·가구·주택·사업체(센서스) | 집계구 · 연 | 약관 원문 미확인(공공데이터법상 영리 이용 금지 불가가 원칙 · 출처 표시) | **이미 키 있음** — 약관 원문 확인 후 사용 |
| — | 서울시×KT 수도권 생활이동 (서울 열린데이터 OA-22300) | 출발→도착 · 목적 · 시각 | 경기는 **시군구** | 공공누리 1유형 | 이미 씀(상권 흐름) — 거점 단위 유동은 못 준다 |

- 역 중심 거점이 많아 **2번이 가장 직접적**이다 — 경기 서빙 거점의 역(야당·문산·행신 = 경의중앙선, 원당·백석·대화 = 일산선)이 모두 코레일 구간이다.
  시간대별 승하차가 서울 TRDAR 「시간대 유동」의 대리값이 될 수 있다(같은 스키마는 아니다 — 역 하나이고, 거점 반경 안 유동이 아니다).
- 1번은 거점 행정동(상가정보 `adongCd`)에 바로 붙는다 — 배후 인구·연령 구성은 Program 의 「누가 사는 곳인가」 재료다.
- 3번은 경기도 전 정류소가 하루 단위로 나온다 — 거점 반경 안 정류소를 합하면 거점 단위 대중교통 수요가 된다.
