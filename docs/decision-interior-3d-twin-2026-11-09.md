# 상권 맞춤 인테리어 — AI 이미지 생성 대신 3D 디지털 트윈 (2026-11-09 사용자 결정)

사용자 요청(그대로):
1. AI 이미지 생성이 아닌 3D 디지털 트윈으로 구성한 개략배치도 및 공간 정보를 활용하여 공실 내부를 3D 디지털 트윈
2. 3D 디지털 트윈 후 공간 구성을 위한 키워드 제공 — #포토존 #창가자리 #우드톤 #갤러리 #빠른 픽업 #초록 식물 #미니멀 #우드 #내추럴 #레트로 #빈티지 #깔끔 #무채색 #화려함 #심플
3. 키워드를 클릭하여 설정하면 3D 디지털 트윈이 선택된 키워드에 맞게 가구 · 의자 · 인테리어 물품 등을 스스로 세팅
4. 디자인 방향 · 공사범위 · 기존 내부 화장실 · 공사 전 체크리스트 칸은 그대로 둠
(1~4 의 예시 5가지 이상을 먼저 HTML 로 — 실제 공실 7곳 · 프로덕션 트윈 데이터로 만들어 전달했다.)

## 3D 내부를 무엇으로 세우나

- 공간: 개략 배치도의 **임대 공간**(일반건축물 · 층 바닥 × 상업층 전용률 추정) → 없으면 **가장 큰 전유부 호실**(집합건물) → 없으면 외곽선 전체.
- 막힌 칸: 공용 · 계단 · 승강기(대장 표제부 대수) — 자리는 개략.
- 벽 · 창: V-World 외곽선 · 외벽 창(`windowSpans` · 표현용). 1층 전면은 통유리. 지하는 창 없음.
- 입구: 전면 변(도로명주소 도로 × OSM) 가운데. 문 앞 1.6m 와 입구 → 안쪽 통로(1.2m)는 비운다.

## 키워드 → 배치 규칙(`src/lib/interiorLayout.ts` · 결정적 — 같은 입력이면 같은 배치)

| 키워드 | 놓는 것 · 바꾸는 것 |
|---|---|
| 포토존 | 입구에서 먼 벽에 아치 포토월 · 스폿 2 · 앞 촬영 여유 1.5m |
| 창가자리 | 전면(창) 벽을 따라 바 테이블 · 스툴(한쪽 4.8m · 좌석 상한의 절반까지) · 지하면 놓지 않고 이유를 적는다 |
| 빠른 픽업 | 입구 옆 주문·픽업 카운터 · 키오스크 · 픽업 선반(안쪽 카운터 대신) |
| 초록 식물 | 옆벽 식물 벽 · 모서리 · 창가 화분 |
| 갤러리 | 옆벽 액자(식물 벽 반대쪽) · 진열형이면 전시 받침대 |
| 빈티지 | 짙은 원목 · 가죽 의자 · 소파 벤치 · 전구 펜던트 |
| 레트로 | 체크 타일 · 원형 테이블 · 머스터드 · 레드 · 펜던트 |
| 화려함 | 포인트 색 · 샹들리에 · 러그 · 화분 더 |
| 우드톤 · 우드 · 내추럴 | 원목 마루 · 원목 가구 · 베이지 벽 · 패브릭 |
| 미니멀 · 깔끔 · 심플 | 밝은 색 · 장식 줄임 · 통로 +0.2m · 좌석당 +0.5㎡ |
| 무채색 | 마지막에 색을 지운다(화려함 · 레트로와 함께면 충돌 안내) |

- 업종: 카페 · 음식이면 좌석형(테이블 · 의자), 그 밖이면 진열형(벽 선반 · 진열대).
- 좌석 상한 = 공공데이터 넓이 ÷ 좌석당 넓이(기능중심 1.7 · 가성비 2.1 · 고급화 2.8㎡). 칸 모양은 외곽선에 맞춘 개략이라
  모양만으로 채우면 실제 넓이보다 좌석이 많아질 수 있어서다(예시 HTML 첫 판에서 익선 브런치 98석 → 상한 83석).

## 지어내지 않는 것

- 화면은 늘 「3D 디지털 트윈 · 규칙 배치 예시 · 실측 도면 아님」. 좌석 수 · 통로 폭 · 가구 크기는 규칙의 예시 값이다 —
  피난 · 장애인 접근 · 업종별 설비 기준을 확인한 값이 아니다.
- 상권 적합도 · 어울림 점수를 만들지 않는다(종전 원칙 그대로).
- WebGL 이 안 되면 같은 배치를 평면(위에서 본 그림)으로 보인다.
