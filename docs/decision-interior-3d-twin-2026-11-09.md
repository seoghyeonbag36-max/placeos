# 상권 맞춤 인테리어 — AI 이미지 생성 대신 3D 디지털 트윈 (2026-11-09 사용자 결정)

사용자 요청(그대로):
1. AI 이미지 생성이 아닌 3D 디지털 트윈으로 구성한 개략배치도 및 공간 정보를 활용하여 공실 내부를 3D 디지털 트윈
2. 3D 디지털 트윈 후 공간 구성을 위한 키워드 제공 — #포토존 #창가자리 #우드톤 #갤러리 #빠른 픽업 #초록 식물 #미니멀 #우드 #내추럴 #레트로 #빈티지 #깔끔 #무채색 #화려함 #심플
3. 키워드를 클릭하여 설정하면 3D 디지털 트윈이 선택된 키워드에 맞게 가구 · 의자 · 인테리어 물품 등을 스스로 세팅
4. 디자인 방향 · 공사범위 · 기존 내부 화장실 · 공사 전 체크리스트 칸은 그대로 둠
(1~4 의 예시 5가지 이상을 먼저 HTML 로 — 실제 공실 7곳 · 프로덕션 트윈 데이터로 만들어 전달했다.)

## 3D 내부를 무엇으로 세우나

- 공간: 개략 배치도의 **임대 공간**(일반건축물 · 층 바닥 × 상업층 전용률 추정) → 없으면 **가장 큰 전유부 호실**(집합건물) → 없으면 외곽선 전체.
- 막힌 칸: 공용 · 계단 · 승강기(대장 표제부 대수) — 자리는 개략.
- 벽 · 창: V-World 외곽선 · 외벽 창(`windowSpans` · 표현용). 1층 전면은 통유리. 지하는 창 없음.
- 입구: 전면 변(도로명주소 도로 × OSM) 가운데. 문 앞 1.6m 와 입구 → 안쪽 통로(1.2m)는 비운다.

## 키워드 → 배치 규칙(`src/lib/interiorLayout.ts` · 결정적 — 같은 입력이면 같은 배치)

| 키워드 | 놓는 것 · 바꾸는 것 |
|---|---|
| 포토존 | 입구에서 먼 벽에 아치 포토월 · 스폿 2 · 앞 촬영 여유 1.5m |
| 창가자리 | 전면(창) 벽을 따라 바 테이블 · 스툴(한쪽 4.8m · 좌석 상한의 절반까지) · 지하면 놓지 않고 이유를 적는다 |
| 빠른 픽업 | 입구 옆 주문·픽업 카운터 · 키오스크 · 픽업 선반(안쪽 카운터 대신) |
| 초록 식물 | 옆벽 식물 벽 · 모서리 · 창가 화분 |
| 갤러리 | 옆벽 액자(식물 벽 반대쪽) · 진열형이면 전시 받침대 |
| 빈티지 | 짙은 원목 · 가죽 의자 · 소파 벤치 · 전구 펜던트 |
| 레트로 | 체크 타일 · 원형 테이블 · 머스터드 · 레드 · 펜던트 |
| 화려함 | 포인트 색 · 샹들리에 · 러그 · 화분 더 |
| 우드톤 · 우드 · 내추럴 | 원목 마루 · 원목 가구 · 베이지 벽 · 패브릭 |
| 미니멀 · 깔끔 · 심플 | 밝은 색 · 장식 줄임 · 통로 +0.2m · 좌석당 +0.5㎡ |
| 무채색 | 마지막에 색을 지운다(화려함 · 레트로와 함께면 충돌 안내) |

- 업종: 카페 · 음식이면 좌석형(테이블 · 의자), 그 밖이면 진열형(벽 선반 · 진열대).
- 좌석 상한 = 공공데이터 넓이 ÷ 좌석당 넓이(기능중심 1.7 · 가성비 2.1 · 고급화 2.8㎡). 칸 모양은 외곽선에 맞춘 개략이라
  모양만으로 채우면 실제 넓이보다 좌석이 많아질 수 있어서다(예시 HTML 첫 판에서 익선 브런치 98석 → 상한 83석).

## 지어내지 않는 것

- 화면은 늘 「3D 디지털 트윈 · 규칙 배치 예시 · 실측 도면 아님」. 좌석 수 · 통로 폭 · 가구 크기는 규칙의 예시 값이다 —
  피난 · 장애인 접근 · 업종별 설비 기준을 확인한 값이 아니다.
- 상권 적합도 · 어울림 점수를 만들지 않는다(종전 원칙 그대로).
- WebGL 이 안 되면 같은 배치를 평면(위에서 본 그림)으로 보인다.

## 2차(같은 날 사용자 요청) — 키워드 30 · 직접 배치 편집기 · 의자 · 책상 따로 · Posting 첫 화면

사용자 요청(그대로): 「공간 키워드 더 다양하게 구성 추가한 후 가구 더하기에 의자, 책상만 따로 추가 가능하도록 기능 추가한 후
상권 맞춤 인테리어 main에 배포 후 Posting 맨 처음 순서로 이동시켜줘」 — 그 전에 예시 HTML(직접 배치 편집기 · 실제 공실 5곳)을 먼저 보였다.

**키워드 15 → 30**(앞 15개는 사용자 지정 순서 그대로). 화면은 네 갈래(`KEYWORD_GROUPS`)로 묶는다.

| 갈래 | 더한 키워드 | 바꾸는 것 |
|---|---|---|
| 자리 · 공간 | 노트북석 · 1인석 · 단체석 · 소파존 · 오픈 키친 | 옆벽 책상 줄(74cm · 한 자리 80cm) · 옆벽 높은 바(105cm · 60cm) · 6인 장테이블(최대 2) · 소파 세트(최대 2) · 긴 카운터(최대 4m) |
| 좌석 수 · 동선 | 좌석 우선 · 여유 동선 | 좌석당 넓이 −0.3㎡ · 통로 −0.15m(최소 1.5㎡ · 0.75m) / +0.5㎡ · +0.3m — 둘 다면 여유 동선 |
| 분위기 · 스타일 | 모던 · 인더스트리얼 · 북유럽 · 아늑함 | 색 · 바닥 · 펜던트 · 러그(아늑함은 좌석당 +0.3㎡) |
| 소재 · 색 · 조명 | 대리석 · 노출 콘크리트 · 파스텔 · 따뜻한 조명 | 상판 · 바닥 · 벽 · 전구색 펜던트 |

좌석당 넓이 · 통로는 `seatRules`(엔진과 편집기가 같은 값). 모두 규칙의 예시 값이다 — 법정 기준이 아니다(「여유 동선」도 휠체어 기준을 확인한 값이 아니다).

**직접 배치 편집기**(`src/lib/interiorEdit.ts` · `components/interior/InteriorEditor.tsx`)
- 키워드로 먼저 놓는다 → 테이블 세트는 고른 디자인(테이블 모양 · 2인석 비율 · 의자 5종 · 상판 · 의자 색)으로 다시 채운다(`refill` — 엔진의 좌석
  채우기는 의자 크기를 모른다). 좌석 상한 = 넓이 ÷ 좌석당 넓이, 세트 사이 통로 · 입구 앞 1.6m · 주 통로 1.2m · 카운터 앞 1.2m 를 지킨다.
- 평면 · 3D 에서 끌어 옮기기, R 회전 · D 복제 · Del 삭제 · 화살표 · 되돌리기. 옮길 때마다 검사(겹침 · 벽 밖 · 입구 막힘 · 주 통로 · 좁은 통로 · 상한 초과).
- 직접 옮긴 뒤 키워드를 바꾸면 자리는 그대로 두고 알린다(색 · 바닥 · 조명만 바뀐다) — 「처음부터 다시 배치」 · 「좌석만 다시 채우기」는 사용자가 고른다.
- **가구 더하기 — 의자 · 테이블 · 책상 따로**: 의자 1개 · 스툴 · 벤치 · 테이블만(70×70 · 120×75 · Ø75 · 180×80) · 책상 100×60. 고른 가구 옆
  빈자리에 놓인다. 의자는 테이블 밑 15cm 까지 겹침이 아니다. 낱개 가구는 겹침만 검사한다(통로는 세트 · 바 · 카운터 · 진열 사이만 잰다).
- 「왜 이 테이블 · 의자 · 개수인가」 — 좌석 상한 계산 · 실제 좌석 · 세트별 바닥 사용표(의자 디자인 반영) · 지키는 거리 · 의자 디자인 이유.
  상권 손님의 **일행 규모 자료는 없다** — 2인 · 4인 비율은 규칙 값이고, 현장에서 세어 맞추라고 화면에 적는다.
- 패널(약 420px)에서는 세로로 쌓고, 「크게 편집」은 문서 맨 위에 전체 화면으로 띄운다(두 칸). WebGL 이 안 되면 평면 편집만 남는다.

**Posting 첫 화면** — 쪽 순서 「상권 맞춤 인테리어 → 자리와 비용 조건 → 주변 업종 지도 → 찾아오는 길」, 처음 여는 쪽도 인테리어다.
자리 · 비용 입력은 처음부터 그려 둔다(`ConsolePages.keepMounted`) — 지도 탐색에서는 왼쪽 칸에 서 있어 인테리어를 보며 자리를 바꾸고,
자동 계산도 그대로 돈다. PPPP 네 화면 · 레일 · 진입로는 건드리지 않았다(가드 · 실화면 검사 22/22 통과).

## 3차(같은 날 사용자 요청) — Posting 에서 업종을 바꾸면 키워드 · 직접 배치도 바뀐다

사용자 요청(그대로): 「Posting 페이지에서 업종을 변경할 경우 변경에 따른 공간 구성 키워드 및 직접 배치도 바뀌도록 설정 후 MAIN에 배포」

- 업종 → 기본 키워드(`industryKeywords` · **규칙** — 상권 · 고객 자료로 고른 값이 아니라고 화면에 적는다). 위에서 처음 맞는 줄:
  테이크아웃 · 브런치 · 베이커리/디저트 · 카페 · 주점/바 · 음식점 · 의류/잡화 · 화장품 · 미용/뷰티 · 편의점/마트 · 꽃/식물 · 서점/문구/공방.
  맞는 줄이 없으면(예: 일반 숙박) 키워드는 그대로 두고 그렇게 적는다.
- Posting 「업종」(직접 입력 · 추천 칩 · 세부 업종) → 인테리어 「디자인할 업종」이 따라 바뀌고, 입력이 0.5초 멈춘 뒤 키워드를 그 업종 기본값으로
  바꾼다(「이전 키워드로 되돌리기」). 처음 열 때도 그 업종의 기본 키워드로 시작한다.
- 업종이 바뀌면 **직접 옮긴 배치가 있어도 새로 놓는다**(좌석형 · 진열형이 갈리고 가구 구성이 통째로 달라진다). 이전 배치는 「되돌리기」로 돌아간다.
  키워드 · 전략만 바뀔 때는 종전대로 직접 옮긴 자리를 지키고 알린다.
