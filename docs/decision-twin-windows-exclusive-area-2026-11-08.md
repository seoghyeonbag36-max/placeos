# 3D 트윈 — 외벽 창문 · 전용면적 따로 표시 · 3D 개략 배치 (2026-11-08 사용자 결정)

사용자가 placeos.co.kr 3D 디지털 트윈에 ① 공실 건물 외부 창문 ② 공실을 클릭하면 전용면적을 따로 표시
③ 참고 HTML(`PlaceOS 참고.html` Case 2 「공실 · 3D 트윈」)처럼 3D 에 개략 배치도를 요청했다.

## 바뀐 원칙

종전 `TwinScene.ts` 머리말은 「창호·외장 텍스처는 쓰지 않는다 — 실측이 아니므로」였다. 이번 결정으로 **대상 건물 외벽에 창문을 그린다.**
창 위치·크기는 표현용 그림이고 실측이 아니다 — 범례 「창호·내부는 실측 아님」이 그대로 화면에 남는다.
층마다 한 줄 · 약 3m 간격 · 1층은 통유리 상점 전면 · 지하는 창 없음. 주변 건물에는 그리지 않는다. 해 그림자는 여전히 그리지 않는다.

## 전용면적 — 지어내지 않는다

- `units[].area_m2` 는 건축물대장 전유부(`exposPubuseGbCdNm == "전유"`) 값이다(`data/pipelines/build_expos_units.py`) → **전용면적**.
- `floors[].area_m2` 는 층별개요 바닥면적이다 → 계단·화장실 등 공용을 포함한다. 전용면적이 아니다.
- 화면은 둘을 따로 적는다(오른쪽 패널 · 3D 위 면적 상자). 전유부가 없는 층(일반건축물 — 공실 층 대부분)은 전용면적 「자료 없음」이다.
  전용률을 가정해 추정값을 만들지 않았다 — 저장소에 전용률 근거가 없다. 추정을 넣으려면 비율과 근거를 정하는 사용자 결정이 먼저다.

## 개략 배치 — 참고 시안의 무엇을 옮겼나

- 옮긴 것: 고른 층을 열고(반투명) 위층을 비쳐 보이게 해 그 안에 호실 칸을 세우기 · 칸 크기 = 전용면적 비례 · 칸 라벨 「호 · 전용 ㎡」 · 「▼ 전면 · 도로」.
- ~~옮기지 않은 것: 시안의 코어·복도·앞줄/뒷줄~~ → 같은 날 **아래 추가 결정으로 옮겼다**(넓이는 대장 값 · 자리는 개략). 호실별 공실 색은 여전히 옮기지 않는다(호실별 공실은 모른다).
- 칸은 건물 긴 변을 따라 놓고 실측 외곽선 안으로 자른다(`planLayout`). 2D 개략 배치도와 3D 가 같은 칸을 쓴다.
- 층 면적을 모르면 외곽선 넓이를 기준으로 삼는다. 호실이 층의 일부만 덮으면 한 모서리에 블록으로 모으고 나머지는 「공용·기타」다(기준 60% → 추가 결정에서 50%).
- 「▼ 전면」은 트윈 `roads`(OSM) 중 도로명주소 도로(`road_check.found`)에서 가장 가까운 점 방향이다. 못 찾으면 달지 않는다.
- 상단 「개략 배치」 버튼으로 끄면 외관(창문)만 본다.

## 추가 결정 — 개략 배치도를 참고 시안 형식으로 (2026-11-08 · 같은 날 후속)

사용자가 「공공데이터로 받은 개략배치도 관련 데이터를 html 파일처럼」 배치도에 올리라고 했다. 종전 `layoutUnits` 주석은
「시안의 코어·복도·앞줄/뒷줄은 지어낸 값이라 옮기지 않았다」였다. 이번에 옮기되 **넓이와 자리를 갈라** 지어낸 값이 실측처럼 보이지 않게 했다.

| 요소 | 넓이(공공데이터) | 자리·모양 |
|---|---|---|
| 호실 칸 | 건축물대장 전유부 전용면적(실측) | 개략 — 앞줄 왼→오, 다 차면 뒷줄(한 호실이 두 줄에 걸치면 두 조각) |
| 임대 공간(일반건축물) | 층 바닥면적 × 상업층 전용률(추정 · `platform_exclusive_ratio.json`) | 개략 — 앞줄 + 공용 옆 |
| 공용(계단·화장실·복도) | 층 바닥면적(층별개요) − 전용 | 개략 — 뒤 모서리 블록, 호실 4개 이상이면 폭 1.8m 복도로 일부를 나눈다 |
| 전면 | 도로명주소 도로 × OSM 도로(실측 위치) | 바깥 법선이 도로 쪽인 외곽선 변(굵은 선) |
| 공실 빗금 | 층 공실 판정(상가정보 대조 · 현장 미확인) | 임대 공간 칸 — 호실별 공실은 모르므로 호실 칸에는 칠하지 않는다 |
| 외곽선 · 치수 · 축척 | V-World 외곽선(실측) | 화면 위 = 북 |

- 승강기(EV)는 표기하지 않는다 — 승강기 수는 표제부에 있지만 Gold 에 싣지 않았다(실으면 「계단·EV·WC」로 바꿀 수 있다).
- 호실이 층의 절반 미만(집합건물 일부 상업 전유)이면 나머지를 공용으로 단정하지 않고 「공용·기타」로 둔다.
- 「전용 + 공용 = 층 바닥」 줄은 배지로 실측 · 계산 · 추정을 나눈다. 화면은 늘 「실측 도면 아님」.
- 층별개요의 **용도별 행**(예: 1층 소매점 · 주차장 · 계단실)은 bronze 에만 있다(Gold 는 층당 한 줄로 접는다). Gold 에 실으면
  용도별 칸으로 더 나눌 수 있다 — 수집 PC 재빌드가 필요하다.
