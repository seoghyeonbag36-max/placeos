# 5개 업종 추천 확장: 필요한 데이터와 연결 조건

대상: 술집, 미용·네일, 옷·잡화, 학원·교육, 운동·여가.
전시·공연은 이번 확장 대상에서 제외한다.

## 이미 있는 데이터

2026-10-16 로컬 산출물 확인:

- 상가정보 Gold 그래프: 점포 ID, 위치, 소분류, 거점, 공간 이웃 관계.
- `gold/features/trdar_demand.parquet`: 352행·46열. 성별·연령별·시간대·주말 유동인구,
  시간대 매출 비중, 점포·개폐업 지표 등. 여러 업종을 합산한 상권 단위 피처다.
- `gold/features/page_building.parquet`: 219,542행·12열. 점포·거점 키와 건물 규모·층·귀속 여부 등.
- `gold/features/adong_hourly.parquet`: 136행·16열. 행정동 시간대 생활인구.
  현재 추가 실험에서는 사용하지 않는다. 학습기에 있는 경로는 Silver 좌표 캐시와 결손 평균
  대체에 의존하므로, 새로 켜기 전에 Gold 귀속 테이블과 결손 계약을 먼저 검증해야 한다.

표의 행 수는 고유 점포 수 또는 커버되는 서빙 거점 수가 아니다.
기존 수요 테이블은 최근 분기 평균을 사용하므로 과거 시점 검증용 패널을 대신할 수 없다.
없는 유동인구나 매출을 임의 추정해 새 학습 행으로 만들지 않는다.

### 이번에 확인·정리한 분기 원천

`bronze/platform13/2026-09-24/seoul_trdar_selng.json`에 142,984행이 이미 있었다.
2021년 1분기~2026년 2분기 22개 분기, 서빙 81거점의 원천으로,
호프-간이주점·미용실·네일숍·피부관리실·일반의류·신발·가방·일반교습학원·외국어학원·예술학원·
스포츠 강습·스포츠클럽·골프연습장·PC방·노래방 등 원천 업종명이 확인됐다.

`build_industry_outcome_panel.py`로 Silver를 거쳐
`gold/features/industry_outcome_panel_2026-10-16.parquet`를 만들었다.
142,984행을 보존했고, **존재하는 행 안에서** 매출·거래 건수 결측은 각각 0이다.
누락된 상권×업종×분기 조합까지 완전하다는 뜻이 아니다. 없는 조합은 0으로 추가하지 않았다.
보고서는 `reports/industry_outcome_panel_2026-10-16.json`에 원천·산출물 해시와 함께 있다.

따라서 이 기간의 동일 원천을 사용자에게 다시 요청할 필요는 없다. 먼저 실제 업종 코드의
대응과 분기별 공백을 검증해야 한다. 공개 추정매출은 검증 후보이며 점포 실측 매출로
바꾸어 부르지 않는다. 이 패널은 로컬 검증용이고 런타임 서빙에는 연결하지 않았다.

## 우선 필요한 공통 데이터

| 목적 | 필요한 필드 | 필요한 입도·연결 키 |
|---|---|---|
| 현재 업종 분류의 오류 진단 | 안정적인 점포 ID, 원천 업종 코드·명, 좌표, 건물 ID, 층, 관측일, 영업상태 | 점포 단위. 상호만으로 합치지 않으며 업종 코드 대응표 필요 |
| 추천 상권 순위의 사후 검증 | 기준 분기, 상권 코드·경계 버전, 세부 업종 코드, 점포 수, 추정매출·거래 건수, 개·폐업 수, 결측·비공개 여부 | 상권×업종×분기. 같은 키의 여러 시점이 필요 |
| 점포 생존 검증 | 익명화된 안정 ID, 개업일, 폐업일 또는 확인한 영업상태·확인일, 위치·업종 변화 | 추적 가능한 점포 시계열. 미관측을 폐업으로 간주하지 않음 |
| 입점 가능성 검증 | 건물·층·호, 면적, 용도, 전력·급배수·환기·소음·주차·접근성 등 확인된 조건 | 실제 후보 매물 단위. 모르는 조건은 결측으로 유지 |

현재 점포 분류와 미래 사업 성과는 서로 다른 정답이다. 성과 검증 자료는 같은 시점의 업종
정답을 추측하는 입력으로 붙이지 않고, 기준일 이후의 평가 대상으로 분리한다.
기존 `build_trdar_demand`가 업종별 매출을 합산한 것은 라벨 누출 방지를 위한 의도다.
그 가드를 없애는 방식으로 세부 업종 성능을 올리지 않는다.

## 업종별 추가 피처 후보

아래는 수집·실험할 후보이며 성능 개선 효과가 입증된 필수 공식은 아니다.

| 업종 | 우선 검토할 추가 정보 | 사업자가 제공할 수 있으면 유용한 집계 |
|---|---|---|
| 술집 | 요리·생맥주·유흥 구분, 야간·주말 소비와 보행 유입, 주변 영업시간, 시설·입점 제약 | 시간대별 거래 건수·객단가·영업시간 |
| 미용·네일 | 헤어·네일·피부관리 구분, 주거·직장 고객층, 예약형 경쟁점의 접근성 | 월 예약 수·취소율·재방문율·시술별 소요시간 |
| 옷·잡화 | 의류·신발·가방·잡화 구분, 고객 연령, 구매 목적의 보행·소비, 점포 전면 노출 | 월 거래 건수·객단가·반품률·상품군별 매출 |
| 학원·교육 | 과목·대상 학령, 학교·학생 분포, 통학 경로, 경쟁 학원의 교습과정·정원 | 월 수강생·정원·수강료·유지율 |
| 운동·여가 | 시설 유형, 주거·직장 생활권, 면적·층·하중·주차·소음 조건 | 유효 회원·재등록·시간대 이용률·예약 수 |

원장·고객 이름, 연락처, 개인별 이동 경로는 이 요구사항에 필요하지 않다.
사업자 집계는 확보 가능할 때 활용하며, 없어도 현재 점포 데이터 기반 연구는 진행할 수 있다.
다만 그 경우 매출·생존·수익성 추천으로 표현하지 않는다.

## 확보 경로

- 서울시 상권분석서비스는 업종별 점포·추정매출·인구 등의 공공 분석 자료를 안내한다.
  [공식 서비스 안내](https://golmok.seoul.go.kr/introduce.do),
  [추정매출 데이터](https://data.seoul.go.kr/dataList/OA-15572/F/1/datasetView.do).
  공개 추정매출은 점포 POS 실측 매출과 구분해야 한다. 5개 큰 업종의 모든 세부 유형이
  원천 코드와 일대일 대응한다고 가정하지 말고 실제 코드 목록·기간·결손을 검증한다.
- 학령·학교 입지는 [전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do)를
  후보로 검토할 수 있다. 학교 위치만으로 학생 수나 통학 동선을 추정하지 않는다.
- 예약·재방문·반품·회원 유지 집계는 해당 사업자 또는 사용 권한이 있는 파트너 자료가 필요하다.

## 수집·배선 순서

1. 먼저 기존 Bronze의 분기별 원천 보유 여부와 업종 코드·기간·관측일을 감사한다.
2. 부족한 원천만 추가 수집하고, 원본 출처·수집 시점·이용 범위를 함께 기록한다.
3. Silver에서 ID·분류·좌표·시점을 정규화한 후 Gold에 분기 패널·귀속·결손 플래그를 만든다.
4. 학습 시점 이후 정보가 피처에 들어오지 않도록 분리하고 기존 기준선과 같은 표본에서 평가한다.
5. 세부 업종 점수를 큰 업종으로 합칠 규칙과 상권 순위의 검증이 끝난 뒤 API·화면을 연결한다.

추가 데이터가 준비됐다는 것만으로 추천을 활성화하지 않는다. 입지 정보의 효과, 평가 표본,
새 상권·새 시점의 일반화가 확인돼야 하며 기존 출처 응답 계약을 유지한다.
