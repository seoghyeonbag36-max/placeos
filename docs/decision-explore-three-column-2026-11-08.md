# 지도 탐색 칸 배치 · 상권 고르기 지도 (2026-11-08)

## 0. 요청
사용자(2026-11-08 「화면 설계 수정 작업」): PPPP 의 오버레이 지도 크기 · 위치가 맞지 않는다 — 지도가 크고 기능이 작아 쓰기 불편하다.
1. 지역(서울 · 경기 · 광주 · 전주)을 고른 뒤 상권을 고르는 화면(`#/districts`)에 지도를 깔고, 상권을 **색깔별 구역**으로 보인다
   (서울은 81개 상권을 각각의 색으로 구별).
2. PPPP 네 화면은 참고 시안(`Renewal/PlaceOS 참고.html` Case 1)처럼 **지도를 가운데** 두고 기능을 한 화면에 들인다.

## 1. 결정
### 1-1. 지도 탐색(`#/explore`) — 넓은 화면은 칸 배치
| 폭 | 배치 |
|---|---|
| ≥1200px | 머리(단계 · 질문) / **왼쪽(고르기) · 지도 · 오른쪽(답)** — 시안 Case 1 의 `270px │ 지도 │ 390px` |
| 769~1199px | 예전처럼 지도 전체 + 좌측 패널 하나(칸 셋이 차례로 쌓임) |
| ≤768px | 지도 + 하단 시트(72dvh) |

| 트랙 | 왼쪽 칸 | 가운데 지도 | 오른쪽 칸 |
|---|---|---|---|
| Platform | 상권 지도(묶음 · 색칠 기준 · 상권 목록 · 범례) | 상권 외곽선 · 자리 칩 | 상권 요약 · 특징 · 접근성 · 근거(탭) |
| Page | 상권 선택 · 건물 검색 · 필터 · 건물 목록 · 후보 | 공실 · 레이어 토글 · 범례 | 고른 건물 상세(임대료 · 추천 · 층 · 3D) + 레이어 요약 |
| Posting | 자리 · 업종 · 비용 조건 입력 | 자리별 월 임대료 칩 | 계산 결과 · 주변 업종 · 인테리어 · 찾아오는 길(탭) |
| Program | Program 머리말 + 네 기능 메뉴(한 줄 설명) | 행사 · 연계 자리 | 고른 기능 본문 |

- 지도는 앱에 하나(MapHost)라 칸도 MapHost 가 세운다. 트랙 화면은 덩어리를 `MapSlot`(React portal)으로 칸에 꽂는다 —
  상태 · 컨텍스트 · 이벤트는 원래 트리를 따른다. 지도 셸 밖(단독 렌더 · 테스트)에서는 제자리에 그려 DOM 이 예전 그대로다.
- 빈 칸은 그리드에서 걷는다(`mh-no-left` 등). 접기(‹ · Esc)는 좌우 칸을 함께 걷고 지도를 넓힌다(`is-collapsed`).
- 지도 칸 크기가 바뀌면(창 · 접기) SDK 에 알린다(ResizeObserver → autoResize/setSize/refresh).
- 카메라 여백(`mapFitPadding`)은 지도 캔버스 기준으로 잰다 — 넓은 화면에서는 패널이 지도를 덮지 않는다.

### 1-2. 상권 고르기 지도(`#/districts` · 지역별 창업)
- 목록(점 색) │ 지도(같은 색 구역). 색은 `lib/districtColors` — 상권 하나에 색 하나(서울 81곳 81색), 공간 순서(뱀 순서)로
  황금각만큼 색상을 돌려 이웃 상권끼리 색이 벌어지게 했다. **구별용 색이지 순위 · 등급이 아니다.**
- 구역 = `/commercial-districts/outlines` 실측 범위(공식 상권 경계 아님). 외곽선이 없는 상권은 중심에 원으로 남긴다.
- 목록 줄을 누르면 예전처럼 바로 업종 질문, 지도 구역을 누르면 카드 「이 상권으로 계속」으로 한 번 더 확인한다.
- 이름표는 줌 13 이상이거나 고른 · 가리킨 상권만 띄운다(81개를 한 번에 띄우면 글자가 겹친다). 글자는 상권 색 위에 올리지 않는다 —
  흰 바탕 · 고름은 굵은 색 테두리(밝은 색은 흰 글자 대비 4.5:1 미만 — 81색 중 48색).
- **짧은 설명(같은 날 추가 요청 「수제화거리 · 성수역 오피스처럼」)** — 서울만 상권 유형(`/commercial-districts/outlines` 의
  `type_name` · 2026-10-09 서울 분류표 T1~T10). 사람이 붙인 라벨 54곳 · 원본 데이터 분류 27곳을 목록 위 한 줄과 알약 툴팁으로 밝힌다.
  목록 줄(그 상권 색 알약) · 지도 이름표(이름 │ 설명) · 고른 상권 카드가 같은 값을 쓴다. 경기 · 광주 · 전주는 설명 없이 이름만 —
  **사용자 결정(2026-11-08): placeos.co.kr 반영 확인 뒤 따로 지시한다.** 시안의 「수제화거리」 등은 성수동 안 데모 구역 이름이라 옮기지 않았다.
- 화면설계서 5판에 반영: §10-1 칸 배치 · 화면 카드 Q1-o · Q1-r(11-04 분기 — 문서에 없었다) · Q4-r · 규칙 예외(§1-4 · §4-1 · §4-2 C1 · F-13) ·
  통과 조건 F-20~F-22 · 미해결 U14~U16 · 변경 이력 2026-11-08.
