## 3. 항목별로 이 원고에서 미리 보이는 문제

- **익명 심사 가능성(7).** 본문에 서비스명 PlaceOS 와 근거 인덱스 참조가 있다. 익명 심사 요구가 있으면 서비스명과 URL 을 일반 명칭으로 바꾸는 작업이 생긴다 — 이 작업은 사례 연구의 정체성에 걸려 있어 **대표자가 결정**한다.
- **분량(2).** 본문이 규정 분량에 모자라거나 넘으면 §2 선행연구(국내 문헌 3자리가 비어 있다)와 §5 논의에서 조절한다. 한계 절은 줄이지 않는다.
- **KIIT 와 중복(9).** 두 원고는 공유하는 수치·표·절이 없다고 정리돼 있으나, 학회가 '같은 연구 계열의 동시 투고' 를 막는지는 규정이 정한다.
- **초록의 66거점 수치.** 초록이 66거점 기준(동결 입력 묶음)이고 서비스는 현재 81거점이다. 규정과 무관하지만 심사자 질문 가능성이 있어 초록에 '동결 입력 기준' 이 보이는지 한 번 더 본다.
- **미완 자리.** 국내 선행연구 3자리(키트 `domestic-insert-kit.md`) · 정책 함의 초안의 문장·강도 확정 · 저자 정보.
