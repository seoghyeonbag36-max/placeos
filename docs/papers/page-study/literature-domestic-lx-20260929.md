# Page · LX 투고용 국내 선행연구 후보 장부

검토일: 2026-09-29 (클라우드 세션). 대상 원고: 「지적과 국토정보」 하반기호 투고본
([../lx/paper-page-lx.md](../lx/paper-page-lx.md)). 상위 원고: [../paper-page.md](../paper-page.md).

> **이 장부의 등급은 "후보"다. 본문 인용 근거가 아니다.**
> 이 세션은 kci.go.kr · koreascience.kr · lxsiri.re.kr · dbpia 원문 페이지를 열 수 없었다
> (egress 프록시 차단). 아래 서지는 **웹 검색 결과의 제목·URL·요약**으로만 확인했다.
> 검색 요약은 요약 모델이 만든 문장이라 권·호·쪽·저자가 틀릴 수 있다.
> 따라서 **원고에는 내용을 인용하지 않고 `<!-- TODO(문헌) -->` 로 자리만 둔다.**
> 원문(최소 KCI 서지 레코드 + 초록)을 직접 열어 대조한 뒤 상태 칸을 올리고 나서 인용한다.

## 상태 표기

| 표기 | 뜻 | 원고 인용 |
|---|---|---|
| `검색서지` | 검색 결과의 제목·URL 로 존재만 확인. 권·호·쪽은 검색 요약값 | **불가** |
| `서지대조` | KCI/DOI 레코드를 직접 열어 저자·연도·권·호·쪽 확인 | 서지만 가능. 내용 인용 불가 |
| `초록확인` | 공식 초록을 직접 읽음 | 초록 범위의 개념적 관련성만 |
| `원문확인` | 방법·결과 절을 읽음 | 가능 (확인 범위를 참고문헌에 병기) |

지금 이 장부의 모든 행은 `검색서지` 다.

## 원고로 올리는 순서 (노트북에서)

1. K1 · K2 · K3 의 KCI 레코드와 초록을 연다 → 상태를 `초록확인` 으로 올린다. 최소 셋이면 §2 의 세 갈래 중 ①② 가 선다.
2. ③ 은 K6 · K7 중 원문이 열리는 쪽 하나. 둘 다 안 열리면 ③ 은 국외 문헌(Marsden & Pingry 2018 등)과 R-ONE 의 조사통계 성격 설명으로만 간다.
3. 올린 행마다 `../lx/paper-page-lx.md` 의 해당 `TODO(문헌)` 를 채우고 **참고문헌에 확인 범위를 병기**한다
   (상위 원고의 "확인 범위: 출판사 공개 초록·서론" 형식을 그대로 따른다).
4. 검색 요약에 나온 수치(오류 유형 수, 연계 실패 비율, 계수 부호 등)는 원문 대조 전에는 **어디에도 옮기지 않는다.**
