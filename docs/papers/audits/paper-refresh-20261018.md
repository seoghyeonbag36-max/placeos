# 논문 후속 업데이트 점검 — 2026-10-18

후속 요청으로 같은 날 Word와 제출용 ZIP의 동기화를 완료했다. 아래는 최초 Markdown 갱신 시점의 기록이며, Word 비교·구조 검수 및 시각 검수의 한계는 [후속 기록](word-sync-20261018.md)을 따른다.

## 범위와 판단

현행 네 Markdown 원고를 점검했다. 수정 대상은 Platform·Page·Posting 원고, 근거 인덱스와 논문 README다. 과거판·기존 Word·LX/KIIT 파생 원고는 수정하지 않았다. 근거는 로컬 코드·Gold·보존 JSON이며 시드·합성 입력으로 실험 결과를 보충하지 않았다. 새 문헌을 인용하거나 학습·수집·LLM 실호출을 실행하지 않았다.

| 원고 | 추가한 내용 | 유지한 한계 |
|---|---|---|
| Platform | 결과 §4.7: 조건 H의 세부 업종 피처 비교와 공간 이웃 비교. 초록·결론·시드 한계도 해당 범위에 맞게 보완 | 역사적 기각 유지. 층 피처의 이득·업종별 악화 병기. 교통·시간대의 작은 양의 시험 구간을 효과 부재나 견고한 일반화로 표현하지 않음. 추천 활성화·사업 성과 미검증 |

수치는 먼저 [근거 인덱스](../evidence-index.md#update-20261018)의 PLATFORM-V01–V04·PAGE-V01–V02·POSTING-V01에 등재했다. 조건 H는 이번 원고에서 붙인 구분명이며 기존 학습 보고서의 실험명을 바꾼 것이 아니다.

## 수행한 검수

아래 이름은 이번 읽기 전용 검수의 항목명이다. 새 pytest 파일을 추가한 것은 아니다.

- `test_paper_numeric_evidence`: 네 원고 전체의 수치 토큰을 인덱스와 대조해 통과. 기존 검수기와 같이 `pp`/`%p` 표기를 정규화하고 절 번호는 제외했다. 토큰 포함 검사만으로 출처 일치를 보장하지 않으므로 아래 JSON 대조를 별도로 수행했다.
- `test_paper_local_links`: 네 원고의 로컬 파일과 근거 인덱스의 명시적 앵커 존재를 확인해 통과.
- `test_preserved_verdicts`: 작업 시작 HEAD 대비 네 원고의 H 판정표가 동일함을 확인했다. Platform의 갱신 메타데이터·시드 한계·결론 문단 이외 기존 문단은 모두 그대로 남아 있다. Page·Posting은 추가만 했고 Program은 변경하지 않았다.
- `test_refresh_evidence_matches_artifacts`: 피처 팔별 시험 표본·시드 평균 Top-3·대조 대비 차이·구간을 JSON과 대조했다. 실험 입력 노드·엣지·버스 Gold의 SHA-256이 보고서와 일치했다. 공공자료의 부분 Silver·격리 파일·검증 보고서·연구 Gold와 매출 패널의 Bronze·Gold 해시도 보존 보고서와 일치했다.
- `test_refresh_row_accounting`: 수용·격리 행 합계, 격리 식별자의 데이터·후보 제외 확인값, 연구 피처 행 수 및 전체 Silver 미작성 상태를 보존 JSON에서 확인했다. 원천 전체 행을 다시 정규화한 검증은 아니다.
- `test_spatial_comparison_recalculation`: `ml.training.industry_detail_compare.compare()`를 두 보존 원본 보고서에 실행해 저장된 비교표·분할 해시와 일치함을 확인했다. 재학습은 하지 않았다.

시작 상태 확인에는 `python scripts/pppp_status.py`와 `python scripts/chain_status.py --all`을 사용했다. 서빙 모집단은 `ACTIVE_HUBS` 기준이며 보류 거점의 산출물 수를 서빙 수로 계산하지 않았다. 이 진행률을 모델 정확도나 사업 성과로 사용하지 않았다.

## 산출물의 한계

이번 최신판은 Markdown이다. Word 생성·페이지 렌더 검수와 제출처별 파생 원고 동기화는 수행하지 않았으므로 기존 Word를 이번 갱신본으로 제출해서는 안 된다. 기존 문헌의 서지·초록 확인 기록을 유지했으며 문헌 전문을 새로 확인한 것은 아니다. 실제 창업 성과·회수기간·독립 현실 공실 정답·LLM 생성 품질의 평가가 완료됐다는 주장을 추가하지 않았다.
