# 사전등록 — 고양·파주 도시 전체 Page 의 품질 기준 (2026-11-23)

> **사용자 결정(2026-11-23 ③)**: 「품질 기준은 KPI 규칙으로 정한다.」 CLAUDE.md 「네 규칙」을 도시 전체 확장에 그대로 적용한다.
> **결과를 보기 전에 적는다** — 이 문서의 숫자·게이트는 새 6곳의 대장·앵커 대조를 받기 전에 정했다.

## 1. 무엇의 품질인가 — 계측기가 있는 것만

| 축 | 계측기 | 현재(2026-11-23) | 목표 |
|---|---|---|---|
| **도시 커버리지** — 서빙 거점이 도시 점포를 얼마나 덮나 | `python scripts/citywide_store_census.py --city goyang\|paju` → `reports/citywide_census_{city}.json` 의 `served_hub_cover.pct` | 고양 **12.4%** · 파주 **24.3%** | **사용자 결정 대기** — 베이스라인만 고정한다(숫자를 지어내지 않는다) |
| **거점 단위 공실률의 앵커 일치** | `calibrate_vacancy` → `calibration.json` 의 서빙 대표값 vs R-ONE 앵커 격차 | 새 6곳 **미측정**(대장 전) | 서빙 게이트(아래 §2) — 일치는 **정확도 주장이 아니다**(§3) |

「도시 커버리지」는 점포 수 비율이지 상권 품질이 아니다. 거점을 늘려 이 비율이 올라도 **공실 판정이 맞아졌다는 뜻이 아니다.**

## 2. 서빙 게이트 — 사전 고정(= 기존 게이트 그대로)

새 6곳(`GOYANG_PAJU_CITYWIDE_HUBS`)이 서빙 목록(`GOYANG_PAJU_CITYWIDE_SERVED_HUBS`)에 오르는 조건은 다른 배치와 **같다** — 이 확장만 기준을 바꾸지 않는다.
`python scripts/chain_status.py <slug>` 의 단계가 전부 ok 여야 한다:

1. **Tier1** — 건축물대장 실측으로 선 Page 마스터
2. **정밀 커버리지 ≥ 80%**(정밀 분모가 점포 후보 건물을 덮는 비율)
3. **서빙 대표값 앵커 격차 |gap| ≤ 30%p**(서빙 게이트 `tests/test_districts` 의 −20%p 하한 포함)
4. **폴백 앵커 아님** — `calibration.json` 의 `anchor_is_fallback` 가 거짓(`rone_rent` 를 새 매핑으로 다시 돌린 뒤 `calibrate_vacancy`)

## 3. KPI 네 규칙을 이 확장에 적용하면

1. **임계값 단독 금지 — 베이스라인과의 차이.** 앵커 격차 ≤30%p 는 서빙 **게이트**(노출 조건)이지 **정확도 주장**이 아니다. 새 6곳은 전부 **공유 앵커**라(고양시청·탄현역·파주시청 셋을 나눠 쓴다)
   앵커 일치가 독립 검증이 못 된다 — 공유 표본과 맞는 것은 「표본과 같은 방향」일 뿐이다. 따라서 이 6곳에 대해 **「공실률이 정확하다」「서울급 품질이다」라고 쓰지 않는다**(`실력` 확정 금지 — 검정불가가 현행 판정).
2. **불확실성 동반.** 거점마다 점포 수·건물 수·정밀 커버리지를 함께 낸다. 반경이 작은 거점(주교동 311m · 마두1동 485m)은 **표본 소형 문구**를 단다(`hub_caveats.SMALL_SAMPLE`). n 과 구간 없이 「달성」이라 쓰지 않는다.
3. **선택 ≠ 보고.** ① 후보는 **점포 밀도 순 규칙**으로 골랐지 앵커 결과를 보고 고르지 않았다(후보 선정이 앵커 대조보다 앞선다 — 이 문서가 그 증거다).
   ② 게이트를 **통과한 곳만** 보고하지 않는다 — 통과한 수와 못 통과한 수를 **둘 다** `chain_status` 로 낸다. ③ 「주의」 후보를 등록하지 않은 이유(대장 전 판정 불가)를 `finding-citywide-census` 에 남겼다.
4. **계측기 없는 목표는 KPI 가 아니다.** 「도시 전체를 덮는다」는 위 표의 `served_hub_cover.pct` 가 계측기다. 목표값은 사용자가 정할 때까지 비워 둔다. 「서울만큼의 품질」은 계측기가 없어 목표로 두지 않는다.

## 4. 하지 않는 것

- 새 거점의 공실률을 서울 거점과 **같은 축에 놓고 순위를 매기지 않는다** — 순위 묶음은 잣대×시도다(결정 문서 §3-3). 공유 앵커 거점 간 임대·공실 피처는 같다.
- 게이트를 통과하지 못한 거점을 사후에 기준을 풀어 올리지 않는다(광주·전주 2차의 −20%p 하한 전례).
- 「주의」 후보를 대장 판정 없이 등록·서빙하지 않는다.
