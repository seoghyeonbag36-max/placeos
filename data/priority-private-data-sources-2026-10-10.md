# 실제 점포·호실 데이터 확보 경로

## 1순위 — 매출·비용·영업 기간

**현재 실측 원본 미확보. 아래는 확보 경로 조사이며 수집 완료가 아니다.**

가장 빠른 경로는 참여 점포주가 자신의 POS에서 파일을 내려받아 제공하는 것이다.
토스플레이스 공식 가이드에는 `≡ → 매출리포트 → 매출현황 → 엑셀 내보내기`가 명시되어 있다.
분할 결제·분할 취소는 해당 파일에서 빠지므로 결제 내역과 대조해야 한다.
https://guide.tossplace.com/operate/sales-report

캐시노트는 매출·지출 관리와 매장 양수도 정보를 제공한다. 점포주 보유 자료 확보 또는
데이터 제휴 문의 후보이며, PlaceOS가 접근할 수 있는 공개 매출 API가 확인된 것은 아니다.
https://cashnote.kr/
https://cashnote.kr/store-trade-faq/

실제 데이터 공급 문의 창구: 한국신용데이터 **소상공인 데이터 랩**.
매출·매입·품목 자료를 요구사항에 맞게 제공하는 서비스를 공식 안내한다.
문의 주소는 `data@kcd.co.kr`, 사이트는 https://data-lab.kcd.co.kr/ 이다.
제공 가능 지역·기간·공간 입도·금액·식별자 및 이용 조건을 문의할 수 있다.
개별 점포 원본과 전체 비용·이익·호실 연결까지 제공되는지는 별도 확인 대상이다.

### 점포주에게 받을 자료

| 자료 | 필수 내용 | 출처 |
|---|---|---|
| 매출 | 월, 매출액, 환불액, 채널, 집계 범위 | POS·예약·배달·정산 원본 |
| 운영비 | 월별 임대료·관리비·인건비·재료비·수수료·공과금 | 회계 장부·세무대리인 |
| 초기 투자 | 보증금·권리금·시설·장비·인테리어 비용 | 계약서·견적서·지급 증빙 |
| 운영 이력 | 개업일·영업 종료일·휴업 기간·이전 여부 | 점포주 확인·관련 증빙 |
| 연결 키 | 점포 내부 ID·주소·층·호실·운영 기간 | 참여 점포 확인 |

권장 요청 기간은 최근 24개월이며, 보유 기간이 짧으면 실제 기간 그대로 받는다.
카드 정산액과 전체 매출은 별개다. 사업자 식별정보는 제한된 원본 저장소에서 관리하고
분석용 점포 ID로 연결한다. 고객별 거래 정보·전화번호는 요청하지 않는다.

### 전달용 요청 문안 — 아직 발송하지 않음

> PlaceOS의 입점 비용·손익분기점 검증을 위해 귀 점포의 보유 기간 내 월별 매출,
> 비용 장부, 초기 투자 증빙과 개·폐업 이력을 제공받고자 합니다. 점포 주소·층·호실과
> 운영 기간을 함께 확인하며, 매출의 포함 채널과 누락 범위도 알려주시기 바랍니다.
> 자료 이용 범위·보관 기간·접근 권한은 제공 전에 협의하겠습니다.

## 2순위 — 호실별 계약·공실 이력

최우선 제공자는 건물주·관리사무소·해당 상가 담당 공인중개사다. 현재 매물 광고만으로는
실제 계약 조건과 공실 시작일을 확인할 수 없다.

| 자료 | 요청 내용 |
|---|---|
| 임대 현황표 | 건물 주소·층·호실·전용면적·현재 점유 여부·확인일 |
| 계약 자료 | 실제 보증금·월세·관리비·렌트프리·계약 및 입주일 |
| 공실 이력 | 이전 임차인 퇴거일·인도일·새 임차인 입주일·각 날짜 증빙 |
| 공간 증빙 | 호실별 도면·전용면적 확인 자료·건축물대장과의 연결 |

공실 시작일은 최초 광고일과 구분한다. 호가와 체결가도 구분해 저장한다.
네이버 부동산은 후보 매물·중개사 확인 경로이며, 실제 계약·공실 이력 원본 확보와는 별개다.
https://land.naver.com/

한국부동산원 상업용부동산 임대동향조사 마이크로데이터는 추가 신청 후보다.
공식 통계 설명자료는 신청서·확인서 작성 후 시스템 자료실 다운로드 절차를 안내한다.
제공 필드·주소 식별 가능 범위·이용 조건은 신청 화면에서 확인해야 하며, 특정 호실의
연속 공실 이력이 제공된다고 전제하지 않는다. 기존 R-ONE 집계 통계와도 구분한다.
https://mods.go.kr/boardDownload.es?bid=12030&list_no=434408&seq=1

2026-10-10 현재 상업용 마이크로데이터 메뉴는 로그인 화면으로 연결된다.
직접 신청 경로: https://www.reb.or.kr/r-one/portal/micro/commercialMicroPage.do
공식 상업용 임대동향 통계 문의: `053-663-8536`.
로그인·사용 신청을 진행하지 않았으므로 마이크로데이터 원본은 미확보다.

### 전달용 요청 문안 — 아직 발송하지 않음

> PlaceOS의 호실별 공실·재입점 이력 검증을 위해 관리 중인 상가의 임대 현황표,
> 호실별 전용면적과 실제 계약 조건, 퇴거·입주일 증빙을 제공받고자 합니다.
> 확인되지 않은 날짜나 금액은 빈칸으로 두고, 광고 조건과 체결 조건을 구분해주세요.

## 수집 경계

위 경로에 대한 외부 문의·제휴 신청·계정 연결은 아직 실행하지 않았다.
자료 제공자가 없으므로 1·2순위는 원본 확보 대기다. 공개 집계·추정 매출을 점포 실매출로
대체하지 않는다. 민간 원본을 Git·Gold에 바로 넣지 않으며 별도 비공개 인수 경로가 필요하다.
토지이용규제 오류 문의는 사용자가 진행 중이므로 중복 문의·호출은 하지 않는다.
