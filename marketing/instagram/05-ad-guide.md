# PlaceOS 인스타그램 광고 집행 조건

작성·공식 자료 확인: 2026-10-09. 대상은 입점을 준비하는 자영업자와 브랜드 출점 담당자다. 아래 예산·기간·타깃은 **첫 실험 제안**이며 실측 성과·Meta 필수 조건이 아니다. 실제 계정 설정이나 광고 집행은 수행하지 않았다.

## 1. 목표부터 고르기

PlaceOS의 첫 광고 목표는 **입점 준비 중인 유효 잠재고객 확보**로 제안한다. Meta는 사업 목표와 광고 목표를 연결하는 방식으로 캠페인을 구성한다. [Meta Blueprint: 캠페인 목표](https://www.facebookblueprint.com/student/path/211544-ads-manager-objectives)

| 준비 상태 | 제안 목표·목적지 | 주로 볼 결과 |
|---|---|---|
| 문의 접수·응대·개인정보 안내가 준비됨 | 잠재 고객(Leads), 즉시 양식 또는 실제 문의 페이지 | 유효 문의 수·유효 문의당 비용 |
| 실제 체험·가입 동선과 이벤트 검증 완료 | 해당 행동에 맞는 목표와 웹사이트 이벤트 선택 | 가입 후 실제 상권 조회·후보 비교 |
| 접수 동선은 없고 서비스 방문만 가능 | 트래픽(Traffic), 서비스 소개/이용 페이지; 계정에서 지원하면 랜딩 페이지 조회 최적화 | 실제 방문·후속 이용률 |

Meta의 잠재 고객 도구에는 양식·메시지·전화 방식이 있다. PlaceOS는 운영자가 처리 가능한 경로를 선택한다. 양식을 쓸 수 있다는 것과 PlaceOS의 접수 운영이 준비됐다는 것은 별개다. [Meta Blueprint: 잠재 고객 생성](https://www.facebookblueprint.com/student/path/253057-lead-gen-course)

문의 접수가 준비되지 않았다면 문의 모집 광고를 먼저 내보내지 않는다. 준비가 되는 동안 트래픽으로 이용 동선을 검증하거나 집행을 보류한다. 링크 클릭 수를 문의 수로 해석하지 않는다.

## 2. 첫 캠페인의 구체적인 조건

| 항목 | 시작 제안 |
|---|---|
| 관리 방식 | Meta 광고 관리자에서 캠페인·소재·성과 관리 |
| 구조 | 캠페인 1개 → 광고 세트 1개 → 소재 3개 |
| 광고 대상 지역 | 서울·경기·인천 거주/활동 대상으로 시작할 가설. 계정에서 선택 가능한 위치 옵션 확인 |
| 서비스 안내 지역 | **서울 상권 입점 검토**라고 명시. 수도권에 광고한다고 경기·인천 상권 데이터도 제공한다고 주장하지 않음 |
| 나이·성별 | 성인 전체·성별 전체로 시작. 25~54세는 필요할 때 검토할 연령 가설이며 필수 제한 아님 |
| 관심사 | 우선 폭넓게 시작. 별도 실험 시 창업·소상공인·프랜차이즈·매장 운영 관련 항목 중 계정에 실제 있는 항목만 선택 |
| 게재 위치 | 인스타그램만 시험할 때 수동으로 Feed·Stories 선택. Reels는 적합한 세로 영상이 준비되면 추가 |
| 예산·기간 | 14일, 총 매체비 420,000원 제안. 하루 평균 30,000원 수준. 지원되는 총예산과 종료일을 설정하고 비용 확인 |
| 집행 시간 | 초반에는 하루 전체를 관찰; 실제 유효 문의의 시간대가 쌓이면 재검토 |
| 언어 | 초기에는 별도 언어 제한 없이 한국어 소재 사용 제안 |
| CTA | 문의 접수 준비 시 지원되는 문의/신청 CTA, 방문 검증 시 더 알아보기 CTA |

예산은 세금·제작비·결제 관련 비용을 제외한 매체비 제안이다. 하루 평균은 하루별 정확한 지출액을 뜻하지 않는다. 더 작은 예산이라면 소재 2개와 광고 세트 1개로 줄인다. 예산과 고객 가치가 미정이므로 적정 CPA나 예상 문의 수는 계산하지 않았다.

소재 문구로 “새 매장 입점을 준비하는 분”, “브랜드의 다음 출점을 검토하는 담당자”를 직접 부른다. 광고 노출만으로 사용자의 직업·사업 단계가 보장되지는 않으므로 접수 후 확인한다.

Meta는 상세 타깃·맞춤 타깃·유사 타깃과 Advantage+를 안내한다. 초기에는 작은 타깃 집단을 여러 개 겹쳐 나누지 않는 전략을 제안한다. [Meta Blueprint: 오디언스 계획](https://www.facebookblueprint.com/student/path/253166-advantage-plus-audiences)

Advantage+ 화면에서 입력 항목이 **제안(suggestion)**인지 **제한(control)**인지 확인하고, 제안으로 표시된 항목은 엄격한 타깃 제한이라고 보고하지 않는다. 현재 광고 계정의 설정은 확인하지 않았다. 세부 Help Center 일부는 로그인으로 막혀 실제 계정에 제공되는 옵션·확장 범위는 미확인이다.

인스타그램 한정은 이번 채널 검증을 위한 제안이다. Meta 공식 안내는 여러 플랫폼에 배분하는 Advantage+ placements도 제시하므로, 이후 전체 고객 획득 효율을 평가할 때 비교할 수 있다. [Meta: 게재 위치·Reels 소재 안내](https://www.facebook.com/business/ads/facebook-instagram-reels-ads)

## 3. 소재 세 가지와 실제 광고 문구

| 소재 | 첫 문장 | 보여줄 내용 |
|---|---|---|
| 자영업자용 | 계약 전, 월세 말고 무엇을 봐야 할까요? | 상권·공간·비용 체크리스트 |
| 브랜드 담당자용 | 다음 출점 후보, 같은 기준으로 비교하고 있나요? | 상권·층·입지·비용 검토 순서 |
| 서비스 이해용 | 좋은 입점은, 상권을 읽는 것부터. | 공개 가능한 실제 서비스 화면과 이용 방법 |

방문용 본문 예시:

```text
서울에서 새 매장 입점을 준비하고 있나요?
상권과 후보 공간을 살펴보고, 입점 비용을 비교해 보세요.
PlaceOS에서 내 매장의 자리를 검토해 보세요.
```

문의용 본문은 실제 운영 범위가 정해진 뒤 작성한다. 없는 상담·무료 분석·맞춤 보고서 제공을 약속하지 않는다. “창업 성공 보장”, “매출 상승 확정”, “AI가 성공 상권을 정확히 예측” 같은 문구는 쓰지 않는다.

이번 PNG는 일반 게시물·스토리 양식이다. 피드 양식은 광고 배치 미리보기에서 크롭을 확인한다. 스토리 광고는 투표/링크 스티커 안내를 삭제하고 광고 관리자 CTA에 맞게 별도 내보낸다. Reels를 추가한다면 9:16 영상과 안전 영역을 검토한다. [Meta: 세로 소재와 안전 영역](https://www.facebook.com/business/ads/facebook-instagram-reels-ads)

## 4. 유효 문의의 정의와 접수 항목

시작 정의 제안: 실제 매장 입점/출점 담당자이고, 서울 대상 지역을 검토하며, 6개월 안의 준비 계획을 설명할 수 있고, 연락이 가능한 문의. ‘6개월’은 운영 가설이므로 영업 주기에 맞게 변경한다. 준비가 이른 고객은 장기 관심 고객으로 따로 기록한다.

접수 질문 제안: ① 자영업자/브랜드 담당자 구분 ② 검토 지역 ③ 업종 ④ 입점 예정 시기 ⑤ 필요한 도움 ⑥ 답변 받을 연락 경로. 담당자가 실제 제공할 수 있는 도움의 범위로 선택지를 만든다. 개인정보 안내·필요한 동의·담당자의 응대 절차를 준비한 후 수집한다.

양식과 소재를 조정해 문의의 질을 높이는 방식은 Meta 공식 교육에서도 다룬다. [Meta Blueprint: 소재·즉시 양식과 문의 품질](https://www.facebookblueprint.com/student/activity/707407)

## 5. 측정·중단·확대 조건

| 지표 | 계산/정의 |
|---|---|
| 랜딩 페이지 조회당 비용 | 매체비 ÷ 실제 랜딩 페이지 조회 |
| CPL | 매체비 ÷ 중복 제거한 전체 문의 |
| 유효 문의 비율 | 유효 문의 ÷ 전체 문의 |
| CPQL | 매체비 ÷ 유효 문의 |
| 후속 이용 | 광고 유입 후 실제 상권 조회·후보 공간 검토 |
| 고객 획득비용 | 매체비 ÷ 실제 유료 고객; 유료 전환이 확인될 때만 계산 |

분모가 0이면 비용을 0원으로 쓰지 않고 ‘계산 불가’로 표시한다. 노출·도달·CTR·CPC는 소재 진단에 쓰고 최종 성공은 유효 문의와 후속 이용으로 판단한다.

UTM 제안: `utm_source=instagram&utm_medium=paid_social&utm_campaign=placeos_launch&utm_content=founder_checklist` (각 소재에 다른 content 값). 목적지에 실제 분석 도구가 있는지 확인한다. 웹 이벤트는 Meta 이벤트 관리자와 자체 기록에서 한 번씩만 들어오는지 검증한 뒤 최적화에 사용한다. Pixel·Conversions API 연결은 이번 작업에서 수행하지 않았다. [Meta Blueprint: 웹사이트 데이터와 전환 신호](https://www.facebookblueprint.com/student/path/291113/activity/247020)

운영 규칙 제안:

- 첫 3일: 링크 오류·이벤트 오류·지역 오해·문의 접수 오류는 즉시 수정. 성과 승자를 단정하지 않는다.
- 7일: 소재별 유효 문의 수와 비용을 비교. 한 세트 안에서는 노출이 균등하지 않으므로 무작위 A/B 검증 결과라고 부르지 않는다.
- 14일: 문의 품질과 후속 행동을 검토해 유지·수정·중단을 결정. 표본이 적으면 결론을 보류한다.
- 집행 전에 허용 CPQL과 손실 한도를 실제 고객 가치·수익·문의→유료 전환율로 정한다. 자료가 없으면 420,000원 실험 예산 안에서 학습하고 확대하지 않는다.
- 허용 CPQL을 넘었으면 숫자를 맞추려 타깃을 계속 늘리기 전에 소재·폼·목적지를 점검한다. 확대는 허용 비용 이하의 유효 문의와 후속 전환을 확인한 경우만 진행한다.
- 리타기팅은 동의와 실제 타깃 규모가 확보될 때 도입한다. 초기 작은 방문자를 별도 광고 세트로 과도하게 분리하지 않는다.

이 계획은 사업 가설을 시험하는 설계다. CPC·CTR·CPL·ROAS의 업계 평균이나 성공 기준을 임의로 넣지 않았다.
