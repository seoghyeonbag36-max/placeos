# 확인된 인허가 이력 26건 복구

사용자가 승인한 범위: 가로수길 23건, 미아사거리 2건, 수유 1건.

기존 운영용 `data/gold/*/building_history.json`에는 26건이 모두 남아 있었다. 이전 전체 재가공 후보가 운영용 Gold에 반영되지 않았기 때문이다. 운영용 Gold는 중복 추가 없이 그대로 보존했다. 검토용 Gold 후보에서만 빠진 정확히 26건을 복구했다.

|거점|기존 Gold 보존 확인|검토 후보 복구|
|---|---:|---:|
|garosugil|23|23|
|miasageori|2|2|
|suyu|1|1|

`build_building_history.address_pnu()`를 수정해 완전한 본번·부번 뒤의 빈 호수 하이픈과, 같은 구·동의 유일한 괄호 지번을 읽게 했다. 잘린 부번·복수 지번을 추측하지 않는다. 모호해서 보류한 24건은 계속 거절된다.

원본 인허가의 관리번호·주소·원본 파일 해시와 정규화된 26행은 `data/silver/history_recovery_26_2026-10-15.json`에 보존했다. 출처는 기존과 같은 `localdata`이며 지번 단위 이력 계약을 유지한다. 다른 개선 후보나 다른 이력 기록을 운영용 Gold에 반영하지 않았다.

검증:

- 데이터·파서 관련 테스트 26개 통과.
- 기존 Gold 및 검토 후보의 백엔드 이력 테스트 각각 7개 통과, 총 40개 테스트 통과.
- 실제 이력 서비스 로더에서 기존 Gold 26건과 후보 26건 모두 조회 확인.
- 실측 주소 26건의 파서 결과가 승인한 PNU와 일치. 보류 24건은 미연결 유지.
- 후보 변경 전후 기록 차이는 추가 26건, 제거 0건.
- 81거점 품질 감사 오류 0건, 배포 추적/ignore 누락 0건.
- 기존 운영용 Gold 해시 불변 확인. 기존 Gold와 수정 전 후보는 `backups/`에 백업.
